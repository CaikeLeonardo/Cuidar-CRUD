Sistema de cadastro para gestão de pacientes em atendimento homecare.

## Funcionalidades
- Cadastro, consulta, edição e exclusão de pacientes
- Cadastro de funcionários
- Cadastro de familiares e cuidadores

## Tecnologias
- Java
- SQL

## Como rodar
1. Clone o repositório: `git clone https://github.com/CaikeLeonardo/Cuidar-CRUD.git`
2. Abra a pasta `CRUD` na sua IDE (ex.: IntelliJ, Eclipse ou NetBeans)
3. [Configuração do banco, se houver]
4. Execute a classe principal
